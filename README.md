# bry-android-icon

个人维护的 Android 通知图标附加来源仓库，结构与打包格式兼容 [ANIP (Android Notification Icon Project)](https://github.com/BetterAndroid/android-notification-icon-project)，可直接作为 [ColorOSNotifyIcon](https://github.com/fankes/ColorOSNotifyIcon) 的「附加来源图标库」使用。

## 已适配应用

| 应用名称 | 包名 | 格式 | 着色 | 强制覆盖 |
| --- | --- | --- | --- | --- |
| 知音楼 (Yach) | `com.tal100.yach` | `svg` | `#0066FF` | `true` |

## 在 ColorOSNotifyIcon 中使用

1. 打开 **ColorOSNotifyIcon** → **同步来源** → **附加来源**。
2. 来源类型选择 **GitHub Releases**。
3. 填写仓库标识：`owmhbry5/bry-android-icon`。
4. 保存并执行一次同步即可生效。
